# Room & Sun

Демо косметичного бренду для шкіри, яка живе між спекою надворі і сухим повітрям у кімнаті. Картку ніхто не списує.

Покупець може зареєструватися, увійти, зберегти адресу і бачити історію замовлень, зроблених з акаунта. Кошик теж належить акаунту: після виходу його не видно ні гостю, ні іншому покупцю. Гостьове замовлення шукається на `/track` за номером і поштою. У столі магазину `/admin` є залишки, ціни, фото, список акаунтів і статус посилки: placed, packing, shipped, delivered.

## Запуск

```bash
npm install
npm run dev
```

Сайт відкриється на порту 3457. Акаунт покупця: `/account`. Відстеження: `/track`. Стіл магазину: `/admin`. Поки `ADMIN_PASSWORD` не заданий, локальний пароль столу — `demo`. У production без цього пароля стіл не відкривається. Паролі покупців зберігаються як хеш у файлі демо.

Замовлення і правки лежать у `data/store.json`. Цей файл не потрапляє в git.

Щоб лист про замовлення реально йшов, задай усі три змінні в `.env.local`:

```bash
ADMIN_PASSWORD=
RESEND_API_KEY=
ORDER_TO_EMAIL=
ORDER_FROM_EMAIL=
```

Без них замовлення просто лишається в списку на `/admin`.

```bash
npm run lint
npm run build
```

Ціни в батах рахуються за фіксованим орієнтиром 34.50 за долар, не за живим курсом. Доставка теж зразкова, у доларах, і в інтерфейсі переводиться тим самим курсом. Формули на сторінках товарів — зразки, не виробнича специфікація.
