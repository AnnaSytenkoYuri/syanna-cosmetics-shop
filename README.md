# Room & Sun

Превʼю косметичного бренду для шкіри, яка живе між спекою надворі і сухим повітрям у кімнаті. Це не готовий бізнес і не приймає оплату: можна зібрати кошик і пройти навчальне оформлення замовлення. Замовлення лишається в браузері.

## Запуск

```bash
npm install
npm run dev
```

Сайт відкриється на порту 3457.

```bash
npm run lint
npm run build
```

Ціни в батах рахуються за фіксованим орієнтиром 34.50 за долар, не за живим курсом. Формули на сторінках товарів — зразки, не виробнича специфікація.
