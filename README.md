# Room & Sun

Демо косметичного бренду для шкіри, яка живе між спекою надворі і сухим повітрям у кімнаті. Картку ніхто не списує. Замовлення зберігається на сервері демо, доставка рахується за країною, а в адмінці можна змінити ціну, фото і залишок.

## Запуск

```bash
npm install
npm run dev
```

Сайт відкриється на порту 3457. Стіл магазину: `/admin`. Поки `ADMIN_PASSWORD` не заданий, локальний пароль — `demo`. У production без цього пароля стіл не відкривається.

Замовлення і правки лежать у `data/store.json`. Цей файл не потрапляє в git.

Щоб лист про замовлення реально йшов, задай усі три змінні в `.env.local`:

```bash
ADMIN_PASSWORD=
RESEND_API_KEY=
ORDER_TO_EMAIL=
ORDER_FROM_EMAIL=
```

Без них замовлення просто лишається в списку на `/admin`.

```bash
npm run lint
npm run build
```

Ціни в батах рахуються за фіксованим орієнтиром 34.50 за долар, не за живим курсом. Доставка теж зразкова, у доларах, і в інтерфейсі переводиться тим самим курсом. Формули на сторінках товарів — зразки, не виробнича специфікація.
